# 광질 타이쿤 — 설계 문서

작성일: 2026-10-22 · 주소: `/mining-tycoon/` · 파일: `public/mining-tycoon/`

사용자와 5조각으로 나눠 하나씩 확정한 설계다. 숫자는 `js/rules.js` 한 곳에 있다.

## ① 게임 규칙

**한 줄 요약:** 드릴 차로 땅을 파 내려가 광석을 모으고, 연료가 떨어지기 전에 지상에 올라와 팔고,
번 돈으로 차를 업그레이드해 더 깊이 내려가 300m 아래 전설의 보물을 찾는다.

- 땅: 가로 40칸 × 깊이 300m. 새 게임을 시작할 때 **무작위로 만들어 저장**(사람마다 다른 땅).
- 땅 종류: 흙(0m~) → 돌(60m~) → 단단한 바위(150m~, **드릴 3단계부터**). 경계는 ±6m 섞임.
- 용암: 100m부터(2%→4%→6%). 못 파고, 닿으면 체력이 줄어든다. 넓게 파도 **그 칸만 남는다(흐르지 않음)**.
- 위로는 못 판다. ↑로 날아 올라간다.

| 광석 | 깊이 | 값 |
|---|---|---|
| 석탄 | 0m~ | 10원 |
| 구리 | 15m~ | 30원 |
| 철 | 35m~ | 60원 |
| 은 | 60m~ | 150원 |
| 금 | 100m~ | 400원 |
| 루비 | 150m~ | 1,000원 |
| 에메랄드 | 200m~ | 2,500원 |
| 다이아몬드 | 250m~ | 6,000원 |

광석이 나오는 방식은 `world.js`의 `oreAt()` — 사용자가 직접 고쳐 보도록 TODO로 남겨 두었다.

**차의 세 한계**
- ⛽ 연료: 땅속에서 움직이고 팔 때 준다. **지상에서는 안 준다.** 0이면 구조대가 끌어올린다
  (100원 + 깊이×3원). 돈이 모자라면 **외상(빚)** → 다음에 팔 때 먼저 갚음, 빚이 있으면 업그레이드·귀환석 못 삼.
- 🎒 가방: 가득 차면 못 담은 광석은 그 자리에 남아 나중에 주울 수 있다.
- ❤️ 체력: 높이 떨어지거나 용암에 닿으면 준다. 0이면 가방 속 광석을 잃고 지상에서 다시 시작.

**업그레이드 6가지**

| | 효과 | 값 (2/3/4/5단계) |
|---|---|---|
| ⛏️ 드릴 | 파는 속도 ×1 → ×3.6, 3단계부터 바위 | 300 / 1,500 / 6,000 / 20,000 |
| ⛽ 연료통 | 100 → 600 | 200 / 1,000 / 4,000 / 15,000 |
| 🎒 가방 | 8 → 60칸 | 250 / 1,200 / 5,000 / 18,000 |
| 🛡️ 몸체 | 체력 100 → 500 | 300 / 1,500 / 6,000 / 20,000 |
| 🚀 엔진 | 날기 빨라짐·연료 덜 씀 | 300 / 1,500 / 6,000 / 20,000 |
| 💥 파는 범위 | 1칸 → 1×3 → 3×3 → 5×5 (4단계) | 2,000 / 10,000 / 50,000 |

- 💥 넓게 파기는 Q(휴대폰 💥)로 켜고 끈다. 범위 안의 못 파는 칸(용암·드릴이 약한 바위)만 남는다.
- 🌀 귀환석 2,000원: 땅속에서 R → "정말 쓸까요?" 확인 → 지상으로 순간이동.
- 보물: 맨 아래 줄 하나. 캐면 50,000원 + 엔딩, 그 뒤에도 계속 할 수 있다.

## ② 화면·조작

- 상단 막대: 연료·체력·가방·돈·빚(있을 때)·깊이·걸린 시간·파는 범위·귀환석.
- 지상 건물 4개(💰 판매소 · ⛽ 주유소 · 🔧 정비소 · 🛒 업그레이드 상점), 앞에 서면 창이 열린다.
- PC: ←→ 이동·옆으로 파기, ↓ 아래로 파기, ↑ 날기, Q, R, Esc (WASD도 됨).
- 휴대폰: 왼쪽 아래 ◀▲▼▶, 오른쪽 💥 🌀. 가로 화면 권장(세로면 안내).
- 다른 탭으로 가면 **자동 멈춤**(시간도 멈춤). 오른쪽 위 **미니맵**(본 곳만).

## ③ 그림·소리

- 그림 파일 없이 Canvas 도형으로 그린다(나중에 AI 그림으로 바꿀 수 있음 — 유료 가능성 있으니 먼저 상의).
- **손전등 효과**: 차 둘레만 밝고 깊을수록 어둡다.
- 효과음·**배경음악**: 웹오디오로 코드가 직접 만든다. 🔊 단추 설정은 기억한다.

## ④ 저장·순위

- 브라우저 `localStorage` 자동 저장(5초마다·팔기·사기·탭 숨김). 망가지면 "저장이 망가졌어요, 새로 시작할게요".
- 상점의 🔄 처음부터 다시(확인 두 번).
- 순위 두 개(한 판당 한 줄): 💰 번 돈 전체(`/api/mining-tycoon-money/scores`, 팔 때마다 자동) ·
  ⏱️ 보물까지 걸린 시간(`/api/mining-tycoon-time/scores`, 짧을수록 위).
- 부정 검사는 점수 상한·2초 간격만(사용자 결정: 문제가 생기면 그때 직접 지움).

## ⑤ 컬렉션 연결

- 게임 선택 화면 카드 `⛏️ 광질 타이쿤`(혼자 하기 · 순위 기록).
- 시험: `test/mining-tycoon.test.js`(규칙·저장·순위 저장소·모의 실험), `test/server.test.js`(주소·순위 API).

# 2차 업데이트 — 지각 밑, 자동 드릴, 지구 파괴 (2026-10-22 확정)

## ① 더 깊은 땅 + 열보호 + 새 광물

- 첫 번째 엔딩(보물)을 보면 300m 바닥이 부서져 아래가 열린다. 엔딩 전엔 "아주아주 단단한 바닥".
- 층: 🟫 지각 1~300m · 🟧 맨틀 301~600m(열 초당 3, 용암 많음) · 🟥 외핵 601~850m(초당 8) · 🟨 내핵 851~1000m(초당 15). 외핵·내핵엔 용암 없음.
- 파려면: 맨틀 드릴 5단계, 외핵 7단계, 내핵 9단계.
- 🔥 열보호(엔딩 뒤, 값 그대로 = A안): 75% 20,000 / 50% 60,000 / 30% 150,000 / 10% 400,000 / **0% 1,000,000원**.
- 새 광물: 페리도트 15,000 · 스피넬 30,000(맨틀) · 운석철 80,000 · 플라즈마석 150,000(외핵) · 핵 결정 400,000 · 별의 심장 1,000,000원(내핵).
- 드릴 10단계(6~10 엔딩 뒤, 모습이 다 다름: 기본·청동·강철·은·황금·루비·에메랄드·다이아몬드·플라즈마·별빛).
- 연료통 8단계(6~8 엔딩 뒤: 900·1,300·1,800).
- 🛢️ 간이 주유소(처음부터, 5단계): 날지 않을 때 1초에 0.1~0.9 연료가 참. 날 때는 줄기만 함.
- 💸 즉시 팔기(1,000원, 5개까지, 엔딩 전에도): 땅속에서 F로 가방을 판매소 값에 팖.
- 죽으면 가방 속 광물은 전부 사라짐(그대로).

## ② 🤖 자동 드릴

- 엔딩 뒤 5,000원, 동시에 **30대**까지. 광산 쪽에 나타나 혼자 파고 광석은 바로 돈(빚 먼저, 번 돈 순위 포함).
- 파는 힘 = 내 드릴 단계, 속도 = 절반. 빈 굴은 떨어지듯 빠르게.
- ⏳ 수명 120/150/180/240/300초(10,000 / 30,000 / 80,000 / 200,000원). (처음엔 60초였는데 모의 실험에서 손해라 120초로 올림)
- 🧯 자동 드릴 열보호(300,000원, 한 번): 없으면 지각(300m) 밑으로 못 감.
- 게임을 끄면 저장했다가 다시 켜면 남은 시간부터 이어서. 상단 막대에 🤖 대수·번 돈.

## ③ 🌍 두 번째 엔딩 — 지구 파괴

- 🎫 지구 핵 입장권 **100,000,000원(1억)**: 엔딩 뒤 + 열보호 5단계여야 살 수 있음. 엔딩 전엔 상점에 아예 안 보임.
- 쓰면 지구 중심 방으로(땅 지도와 따로 있는 방이라 지도·미니맵에 안 보임). 입장권은 들어갈 때 없어짐.
- 🚪 문: "나가면 입장권이 사라져서, 다시 오려면 또 사야 해요" 확인 후 지상으로.
- 🔴 버튼: 확인 창 두 번("버튼을 누를까요?" → "정말 누를까요?") — **지구가 부서진다는 말은 안 함**.
- 연출: 흔들림·금 → 번쩍 → 우주에서 지구 조각이 흩어짐 → 엔딩 창(총 시간·번 돈·보물 시간·자동 드릴 수) → 처음부터.
- 🌍 지구를 부순 횟수 배지(시작 화면, 새 게임에도 남음) + 🌍 지구 파괴 시간 순위(짧을수록 위).

## ④ 저장·순위·시험

- 저장 `version: 2`. 예전 저장(버전 1)은 위 300m를 그대로 옮기고 아래를 같은 씨앗으로 새로 붙임.
- 엔딩 전 상점: 새 업그레이드는 🔒 "보물을 찾으면 열려요"로 미리 보여 줌(입장권만 비밀).
- 엔딩 창에 "아래로 가는 길이 열렸어요! 🔥 열보호를 사야 버틸 수 있어요" 안내.

## 돈 균형 (모의 실험 결과 → 사용자 결정 2026-10-22)

자동 드릴 30대를 계속 사면서 10분 동안 남는 돈:

| 내 드릴 | 자동 드릴 수명 | 10분 동안 남는 돈 |
|---|---|---|
| 5단계 | 60초 | 약 −104만 원(손해) |

| 7단계 | 120초 | 약 +603만 원 |

→ 수명이 짧으면 손해, 끝까지 키우면 입장권(1,000만 원)이 너무 쌈.

# 3차 업데이트 — 뽑기, 날면서 옆 파기, 설명 창, 히든 엔딩 (2026-10-23 확정)

## ① 🎰 뽑기 (🛒 상점 안)

| | 값 | 나오는 광석(확률) | 언제 |
|---|---|---|---|
| 🎰 일반 뽑기 | 300원 | 석탄 30 · 구리 22 · 철 17 · 은 12 · 금 9 · 루비 6 · 에메랄드 3 · 다이아몬드 1% | 보물 찾기 전까지만 |
| 🌟 특수 뽑기 | 100,000원 | 페리도트 35 · 스피넬 27 · 운석철 18 · 플라즈마석 12 · 핵 결정 6 · 별의 심장 2% | 보물 찾은 뒤부터 |

- 평균으로 낸 돈의 약 90%가 돌아온다(살짝 손해). 뽑은 광석은 가방에 들어가고, 가방이 가득 차면 못 뽑는다.
- 확률표는 `js/rules.js`의 `GACHA` 한 곳에 있다.

## ② ✈️ 날면서 옆으로 파기

- 공중에서 ← → 로 벽에 붙으면 옆을 판다. 차가 두 줄에 걸쳐 있어도 되고, 파는 동안 그 줄 높이로 맞춰진다.

## ③ 📖 설명 창

- 처음 들어오면 한 번 뜨고, 위쪽 ❓ 설명 단추로 다시 본다. 조작법·조심할 것·광석 14종 값·뽑기·엔딩 보는 법.
- 엔딩 1(보물)만 방법을 알려 주고, 엔딩 2는 "또 하나의 엔딩이 있다는 소문", 히든 엔딩은 "??? 2개"로만 쓴다.

## ④ 🤫 히든 엔딩 2개

- 히든 1 🕳️ 지각 정복: 300m까지 팔 수 있는 칸을 다 판다. / 히든 2 🌋 지구 속 정복: 1000m까지 다 판다.
- 용암(원래 못 파는 칸)은 세지 않는다. 자동 드릴이 판 칸도 친다.
- 엔딩 창(걸린 시간) + 시작 화면 배지(새 게임에도 남음). 돈 보상·순위는 없다.
