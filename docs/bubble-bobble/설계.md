# 버블보블 따라만들기 — 설계 문서

작성일: 2026-09-10
프로젝트: P17-버블보블(Bubble Bobble)

---

## 1. 한눈에

1986년 아케이드 게임 **버블보블**을 브라우저에서 도는 웹 게임으로 흉내낸다.
사용자가 엔트리 수업에서 직접 만든 그림·배경음악을 재료로 쓰고, 움직임과 규칙을
원작에 가깝게 만든다. 30판 이상 + 보스, 완성 후 GitHub Pages로 배포한다.

- **실행 방법**: `index.html` 더블클릭 → 브라우저에서 바로 플레이 (설치·빌드 없음).
- **기술**: 순수 HTML + 자바스크립트 + 캔버스 2D. 게임 엔진 없음.
- **재료**: `D:\민결이자료\코딩\엔트리\81강버블보블(인데 쓸모가 없...)` 의 이미지·배경음악을
  `assets/` 로 복사해서 사용. 원본 폴더는 건드리지 않는다.
- **효과음**: 코드로 그 자리에서 만드는 레트로 전자음(WebAudio). 원작 음원은 저작권 때문에 안 쓴다.

### 저작권 경계 (중요)

- 타이토 원작의 스프라이트·음원·정확한 레벨 레이아웃을 그대로 재현하지 않는다.
- 사용자 본인이 만든 그림과 `배경음악.mp3` 는 사용해도 된다.
- 레벨 모양은 원작과 "같은 느낌"으로 새로 그린다. 1판만 사용자의 `지형.png` 배치를 그대로 쓴다.

## 2. 화면과 게임 흐름

### 화면

- **한 화면 고정**(스크롤 없음). 배경은 검정, 그 위에 사탕줄무늬 발판.
- 캔버스 내부 해상도는 `지형.png` 비율(약 4:3)에 맞춘 **512 x 384** 로 잡고, 창 크기에 맞춰
  정수배로 확대(픽셀이 뭉개지지 않게 `image-rendering: pixelated`).
- 좌우 = 벽(막힘). 위아래 = 뚫림 → 아래로 떨어지면 화면 위에서 다시 나온다(래핑).
- 캐릭터 원본 그림은 94px지만 화면에는 **약 24px(타일 1.5칸)** 로 줄여 그린다.

### 좌표계와 타일

- 타일 한 칸 = **16 x 16 px**. 플레이 영역 = 가로 32칸 x 세로 24칸.
- 물리 계산은 픽셀 단위 실수. 발판 충돌은 사각형(AABB) 겹침 검사.

### 상태 머신

```
BOOT(에셋 로딩)
  → TITLE(시작 화면: "PUSH SPACE")
     → PLAYING(플레이)
         → ROUND_CLEAR(과일 점수 합산 연출 ~2초) → 다음 판 PLAYING
         → MISS(죽음 연출 ~1.5초) → 목숨 남으면 같은 판 PLAYING / 0이면 GAME_OVER
     → GAME_OVER("GAME OVER" + 최종점수 + 카운트다운) → 클릭/스페이스 → TITLE
     → ENDING(마지막 판 클리어 시 축하 화면) → TITLE
```

### 게임 루프

`requestAnimationFrame` 으로 매 프레임:
1. 입력 읽기 → 2. 개체 업데이트(이동) → 3. 충돌 처리 → 4. 그리기.
- 프레임 시간이 튀어도 물리가 깨지지 않게 **고정 timestep(1/60초) 누적 방식**.

## 3. 조작

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ | 점프 (짧게 누르면 조금, 오래 누르면 높이 — 가변 점프) |
| Space | 거품 뿜기 |
| Z 또는 X | 거품 뿜기 (Space 대체키) |
| M | 소리 음소거 토글 |
| P | 일시정지 |

- 원작은 점프와 거품이 각각 버튼이다. 우리도 **점프 = ↑, 거품 = Space** 로 분리한다
  (엔트리 원작이 스페이스로 거품을 뿜었으므로 스페이스에 거품을 둔다).
- TITLE·GAME_OVER 화면에서는 Space = "시작/계속".

## 4. 주인공 (버블룬)

- 그림: `주인공1~5.png` 를 걷기 애니메이션 + 거품 뿜는 순간용으로 나눠 사용.
- 물리: 중력으로 항상 아래로 가속, 최대 낙하속도 제한. 지상에서만 점프 가능(코요테 타임 약간 허용).
- **한쪽 통행 발판**: 아래에서 위로는 통과, 위에서 내려올 땐 딛는다. (아래 방향키로 내려가기는 없음 — 원작에 없음)
- **거품 타기**: 적이 안 든 거품 위에 올라서면 살짝 튕겨 올라간다. 계속 밟으면 위로 등반 가능.
- 무적 시간: 부활 직후 약 2초간 깜빡이며 무적.
- 적 또는 적의 투사체에 닿으면 죽는다(MISS).

## 5. 거품

### 생성과 이동

1. 뿜기: 주인공이 보는 방향으로 **초기 속도 빠르게** 발사.
2. 약 0.4초 뒤 속도가 0에 가까워지며 **그 자리에 정지**.
3. 이후 **천천히 위로 부상**, 천장·발판 밑면에 닿으면 옆으로 미끄러지며 모인다.
4. 생성 후 약 8초가 지나면 **자연 소멸**(펑).
- 연사 제한: 마지막 뿜은 뒤 약 0.3초 쿨다운.
- 화면에 존재 가능한 내 거품 최대 개수 제한(예: 6개).

### 적 가두기

- 날아가는 빈 거품이 적과 겹치면 → 그 적이 **거품에 갇힌다**(`방울2.png` 스킨).
- 갇힌 거품은 위로 부상. 일정 시간(예: 5초) 뒤 **적이 거품을 깨고 탈출**(탈출 시 잠깐 화난 상태).
- 갇힌 거품을 주인공이 밟으면 위로 튕길 수도, 부딪히면 터진다(아래).

### 터뜨리기 = 무찌르기

- 주인공이 **갇힌 거품에 접촉** → 거품이 터지고 안의 적이 죽는다. `방울3.png`("POW")를 터지는 순간 1~2프레임 표시.
- 죽은 적은 `적소멸1~3.png` 애니메이션 후 그 자리에 **과일**을 남긴다.
- **연쇄(콤보)**: 거품 하나가 터질 때 닿아 있는 다른 갇힌 거품도 연달아 터진다. 한 연쇄로 터진 적 수에 따라
  더 비싼 과일이 나온다.

### 과일 점수표 (한 연쇄에서 터진 적 수 → 과일)

| 적 수 | 과일 | 점수 |
|---|---|---|
| 1 | 사탕 | 100 |
| 2 | 바나나 | 300 |
| 3 | 복숭아 | 500 |
| 4 | 햄버거 | 700 |
| 5 | 아이스크림 | 1000 |
| 6+ | 다이아몬드 | 3000 |

- 과일은 나온 뒤 약 6초 후 사라진다. 주우면 즉시 점수.
- (그림 준비: 과일 스프라이트는 없으므로 코드로 간단한 픽셀 도형을 그리거나 작은 픽셀아트를 새로 만든다.)

### 특수 거품 (가끔 일반 거품 대신 생성, 확률 낮음)

- **물거품 💧**: 터지면 물줄기가 발판을 타고 아래로 흐르며 닿는 적을 쓸어 화면 밖으로 보낸다(즉사 처리).
- **번개거품 ⚡**: 터지면 수평으로 번개가 뻗어 일직선상의 적을 관통해 즉사.
- **불거품 🔥**: 터지면 그 자리와 아래 발판에 불기둥이 잠깐 남아 닿는 적 즉사.
- 특수 거품으로 죽인 적도 과일을 남긴다(콤보 계산엔 각각 1로).

## 6. 적 (몬스터)

`적1~4.png` 는 같은 파란 몬스터의 걷기 4프레임으로 취급. **색조(hue) 변경**으로 종류를 구분한다.

| 이름 | 색 | 행동 | 등장 |
|---|---|---|---|
| **통통이** | 파랑 | 발판 위 좌우 순찰, 끝에서 방향 전환, 가끔 낮은 점프. 느림. | 1판~ |
| **뿔몬** | 초록 | 통통이 + 가끔 멈춰서 돌 투사체를 수평 발사. 보통 속도. | 4판~ |
| **날개몬** | 분홍 | 발판 무시, 대각선으로 날며 벽·천장·바닥에서 튕김. 빠름. | 8판~ |
| **유령몬** | 보라 | 발판 통과, 주인공 쪽으로 느리게 추적. | 15판~ |

### 공통 AI 규칙

- 시야에 주인공이 없어도 순찰. 주인공이 같은 층·가까이면 그쪽으로 이동 성향 증가.
- 서로 겹치면 살짝 밀어낸다(뭉침 방지).
- 화면 아래로 떨어지면 위에서 다시 등장(주인공과 동일 래핑).

### 화난 상태 (angry)

트리거: ① 그 판에 적이 1마리만 남음 ② 판 시간이 거의 끝남 ③ 거품에서 탈출한 직후(몇 초).
효과: 스프라이트 빨갛게 틴트, 이동 속도 +50%, 점프·방향전환 빈도 증가.

### 심술고래 (원작 Baron von Blubba 대응)

- 한 판에서 **제한 시간을 다 쓰면** 화면 가장자리에서 하얀 고래가 등장.
- **무적**. 벽·발판 전부 통과. 주인공 위치로 빠르게 직선 추적. 닿으면 즉사.
- 판을 클리어하면 사라진다. (그림: 간단한 픽셀 고래를 새로 그린다.)

### 보스 (마지막 판)

- **거대 몬스터** 1마리. 우리 적 스프라이트를 3~4배 확대 + 색 변경.
- 체력제: 거품에 가뒀다가 터뜨릴 때마다 체력 -1 (총 8~10). 화날수록 패턴 빨라짐.
- 패턴: 좌우 이동하며 투사체 뿌리기, 가끔 작은 졸개 소환.
- 넓은 전용 무대(발판 적음). 클리어 시 ENDING.

## 7. 아이템

적을 거품 없이도 잡게 해주거나 능력을 올려주는 아이템. 특정 조건(콤보, 일정 적 처치 수, 낮은 확률 랜덤)에
발판 위로 굴러 나온다. 효과는 **그 판 동안 또는 죽을 때까지** 유지.

| 아이템 | 효과 |
|---|---|
| 👟 파란 신발 | 걷기 속도 증가 |
| 🍬 노란 사탕 | 거품 사거리 증가 |
| 🍭 빨간 사탕 | 거품 연사 쿨다운 감소 |
| 🫧 파란 사탕 | 거품 부상 속도 증가 |
| ☂️ 우산 | 즉시 여러 판 건너뛰기(3/5/7판짜리) |
| 🧪 물약(빨강/파랑/초록) | 화면에 과일이 우르르 쏟아짐(보너스 점수) |
| 💍 반지·왕관 등 | 순수 점수 아이템 |

### EXTEND 글자 풍선

- 갇힌 적을 터뜨릴 때 낮은 확률로 알파벳 풍선(`E` `X` `T` `E` `N` `D`) 중 하나가 떠오른다.
- 주워서 6글자를 모두 모으면 → **목숨 +1** + 즉시 다음 판. HUD에 모은 글자 표시.
- 판이 바뀌어도 모은 글자는 유지. 6개 완성 시 초기화.

### 점수로 목숨

- 누적 점수가 30,000점을 넘길 때마다 목숨 +1 (한 번씩).

## 8. HUD와 화면들 (원작 아케이드 스타일)

### 인게임 HUD

- 상단: `1UP  00000`(왼쪽, 내 점수) · `HIGH  00000`(가운데, 최고 점수) · `ROUND 1`(오른쪽).
- 하단 왼쪽: 남은 목숨을 **작은 공룡 머리 아이콘**으로 나열(숫자 X).
- 하단: 얇은 **시간 막대**가 서서히 줄어듦. 20% 남으면 `HURRY!` 깜빡임 + 심술고래 예고.
- 상단 어딘가: 모은 EXTEND 글자(`E X T E N D`, 획득한 것만 밝게).
- 폰트: 각진 픽셀 비트맵 폰트(코드로 그리거나 CSS `@font-face` 픽셀 폰트). 파란 동그라미 숫자판 안 씀.
- 최고 점수는 브라우저 `localStorage` 에 저장(try/catch).

### 화면들

- **TITLE**: 게임 로고(텍스트), "PUSH SPACE", 조작 안내, 최고 점수.
- **ROUND_CLEAR**: 가운데 `ROUND CLEAR!`, 이번 판에 먹은 과일 점수가 또르륵 합산되는 연출(~2초).
- **MISS**: 화면 짧게 번쩍 + `MISS!` (~1.5초). 목숨 남으면 같은 판 재시작.
- **GAME_OVER**: `GAME OVER` + 최종 점수 + `계속하려면 클릭` + `9…8…7…` 카운트다운(0 되면 TITLE).
- **ENDING**: 축하 메시지 + 총 점수 + 크레딧(사용자 이름, "팬 게임 · 공부용").
- 모든 안내 문구는 쉬운 한국어(개발용 별명·비유 금지).

## 9. 레벨 (판)

### 글자 지도 형식

각 판은 문자열 배열로 정의한다. 한 글자 = 타일 한 칸.

```
'#' 발판     '.' 빈 칸     'P' 주인공 시작
'1' 통통이   '2' 뿔몬     '3' 날개몬   '4' 유령몬
```

예 (설명용 축약 — 실제 판은 32칸 x 24칸을 다 채운다):
```js
{
  time: 30,                 // 제한 시간(초)
  theme: 'pink',            // 발판 색 테마
  map: [
    "################################",
    "#..............................#",
    "#..............................#",
    "#....####............####.......#",
    "#..............................#",
    "#..######..........######......#",
    "#..............1.........1......#",
    "#####......................#####",
    "#..............................#",
    "#....2....................2.....#",
    "#..######..........######......#",
    "#..............................#",
    "#..............................#",
    "#.P............................#",
    "################################"
  ]
}
```

- 로더가 한 번 파싱 → 발판 사각형 목록 + 주인공 위치 + 적 스폰 목록으로 변환. 이후 글자는 안 쓴다.
- 파일 위치: `js/levels.js` (사용자가 메모장처럼 직접 고칠 수 있게 주석 잘 달기).

### 판 구성 (30판 이상 + 보스)

- **1판**: 사용자 `지형.png` 의 발판 배치를 그대로 옮긴다(원작 1스테이지 모양). 통통이 2~3마리.
- **2~10판**: 좌우 대칭 쉬운 구조. 통통이 위주, 적 2~4마리.
- **11~20판**: 발판 복잡, 뿔몬·날개몬 등장, 적 5~6마리.
- **21~29판**: 좁은 통로·비대칭·함정형, 유령몬 등장, 시간 짧아 화난 적 자주.
- **30판**: 보스 무대.
- 원작 100판을 베끼지 않고 같은 느낌으로 새로 디자인. 10판마다 발판 색 테마 변경(분홍→하늘→연두→…).
- 시간이 남으면 31판+ 를 계속 추가할 수 있는 구조.

## 10. 소리

### 효과음 (WebAudio 로 코드 생성)

`js/sfx.js` 에 작은 신시사이저. 오실레이터 + 게인 엔벨로프 + 살짝의 노이즈로 다음을 만든다:
거품 뿜기, 거품 터짐, 점프, 착지, 적 가두기, 적 소멸, 과일/아이템 획득, EXTEND 글자, 콤보,
MISS, ROUND CLEAR, 심술고래 등장, 보스 피격.
- 필요하면 freesound.org 의 **CC0** 소리 몇 개만 받아 `assets/sfx/` 에 넣고 라이선스 메모.

### 배경음악

- `assets/음악/배경음악.mp3` 반복 재생. TITLE/보스/엔딩에서 볼륨·재생 조절.
- 브라우저 정책상 첫 사용자 입력 후 오디오 시작(자동재생 차단 대응).
- `M` 키로 전체 음소거 토글, 상태 `localStorage` 저장.

## 11. 파일 구조

```
P17-버블보블(Bubble Bobble)/
├─ index.html            # 캔버스 + <script> 태그들 + 약간의 CSS
├─ css/
│  └─ style.css
├─ js/
│  ├─ main.js            # 부팅, 게임 루프, 상태 머신
│  ├─ input.js           # 키보드 입력
│  ├─ assets.js          # 이미지·오디오 로더
│  ├─ sfx.js             # WebAudio 효과음
│  ├─ player.js          # 주인공
│  ├─ bubble.js          # 일반/특수 거품
│  ├─ enemy.js           # 적 4종 + 보스 + 심술고래
│  ├─ item.js            # 과일·아이템·EXTEND
│  ├─ level.js           # 글자 지도 파서 + 충돌 도우미
│  ├─ levels.js          # 판 데이터 (사용자가 편집)
│  ├─ hud.js             # HUD + 화면들
│  └─ util.js            # AABB, 난수, 픽셀 폰트 등
├─ assets/
│  ├─ 이미지/            # 원본에서 복사 (주인공/적/방울/지형/배경)
│  ├─ 음악/배경음악.mp3   # 원본에서 복사
│  └─ sfx/               # (선택) CC0 효과음
├─ 설계.md
├─ 실행계획.md            # writing-plans 로 작성 예정
├─ README.md             # 배포용 설명 (팬 게임·공부용 명시, 크레딧)
└─ CNAME                 # (나중에) 커스텀 도메인
```

- 클래식 `<script>` 로딩(모듈 X): `util → assets → input → sfx → level → levels → player → bubble → enemy → item → hud → main` 순서.
- 전역 네임스페이스 하나(`window.BB`)에 모듈을 담아 충돌 방지.

## 12. 배포

게임이 충분히 완성된 뒤:

1. `gh repo create bubble-bobble-clone --public` (프로젝트 폴더에서). 설명: "팬이 공부용으로 만든 버블보블 스타일 게임".
2. `git init` → 첫 커밋 → `git push`.
3. GitHub Pages 활성화(`main` 브랜치 루트). `index.html` 이 루트라 바로 서비스됨.
4. `README.md` 에 플레이 링크, 조작법, 크레딧, "팬 게임(비상업·학습용), 버블보블은 타이토의 상표" 고지.
5. 나중에 사용자가 커스텀 도메인을 알려주면 `CNAME` 파일 추가 + DNS 안내 + Pages 설정.

- 공개 저장소이므로 코드와 사용자 자료(그림·mp3)가 함께 공개됨 — 사용자 동의 완료.
- `.gitignore` 에 `.playwright-mcp/`, OS 임시파일 등.

## 13. 열린 질문 / 나중에 결정

- 2인 동시 플레이(원작 협동): 이번 범위에서 **제외**(YAGNI). 나중에 확장 여지만 남김.
- 과일·아이템·고래·보스 스프라이트: 새 픽셀아트를 그릴지 코드 도형으로 갈지 → 구현 중 결정(우선 코드 도형).
- 점프/거품 키 겸용(Space) 여부: 플레이테스트에서 사용자 피드백으로 확정.
- 판 개수 최종치(30 vs 40+): 8번 조각에서 페이스 보고 조정.
