# 내가 만든 버블보블

1986년 아케이드 게임 *버블보블*을 좋아해서, 비슷한 느낌으로 직접 만들어 본 웹 게임입니다.
공룡이 거품을 뿜어 적을 가두고 터뜨려 판을 깨나갑니다.

## 플레이

- 온라인: https://kmathlove-wq.github.io/bubble-bobble-clone/  (컴퓨터 · 휴대폰 모두 가능)
- 직접 실행: 이 폴더를 내려받아 `index.html` 을 더블클릭하세요.

## 조작

**컴퓨터**

| 키 | 동작 |
|---|---|
| ← → (또는 A D) | 이동 |
| ↑ · W · 스페이스 | 점프 |
| 마우스 왼쪽 클릭 (또는 Z, X) | 거품 뿜기 |
| M | 소리 켜기/끄기 |
| P | 잠깐 멈추기 |

**휴대폰**: 화면 아래 버튼(◀ ▶ / 거품 / 점프). 시작 화면은 아무 곳이나 탭.

## 규칙

- 거품을 뿜어 몬스터에게 맞히면 몬스터가 거품이 되어 천장으로 떠올라요.
- 떠오른 몬스터에 몸을 부딪히면 터지면서 과일이 나와요. 여러 마리를 한꺼번에 터뜨릴수록 점수가 커져요.
- 몬스터를 다 잡으면 다음 판. 30판을 다 깨면 보스가 나와요.
- 너무 꾸물거리면 못 죽이는 하얀 고래가 쫓아와요.
- `E X T E N D` 글자 풍선 6개를 다 모으면 목숨이 하나 늘어요.

## 만든 것

- 그림·배경음악: 김민결 (엔트리 수업에서 만든 것)
- 효과음: 코드로 만든 전자음 (WebAudio)
- 게임 코드: 순수 HTML + 자바스크립트 (게임 엔진 없음)

## 고지

이 프로젝트는 팬이 **공부 목적으로** 만든 것이며 상업적으로 이용하지 않습니다.
*버블보블(Bubble Bobble)* 은 주식회사 타이토(TAITO)의 상표이며, 이 게임에는 원작의
그림·음원·레벨 데이터가 들어 있지 않습니다. 움직임과 규칙만 비슷하게 흉내냈습니다.
