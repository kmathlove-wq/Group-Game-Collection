# 버블보블 따라만들기 — 실행계획

> **작업 방식:** 아래 마일스톤을 위에서부터 하나씩. 각 마일스톤 끝에 "직접 확인" 목록을 통과하면
> 커밋하고 다음으로. 각 단계는 체크박스로 진행 추적.

**목표:** 브라우저에서 도는 버블보블 스타일 게임(30판+보스)을 순수 HTML+JS 캔버스로 만들고 GitHub Pages에 배포.

**구조:** 게임 엔진 없이 `requestAnimationFrame` 고정 timestep 루프. 개체(주인공/거품/적/아이템)는
각자 `update(dt)` / `draw(ctx)` 를 가진 평범한 클래스. 전역 네임스페이스 `window.BB` 하나에 모듈을 담음.
`index.html` 을 클래식 `<script>` 태그로 순서대로 로드 → 파일 더블클릭으로 실행 (file:// 에서 모듈 import는 CORS로 막힘).

**기술:** HTML5 Canvas 2D, WebAudio(효과음), localStorage(최고점수/음소거), gh CLI(배포).

**설계 문서:** `설계.md` (이 계획은 그 문서를 근거로 함 — 둘을 같이 읽을 것).

## 전역 제약 (모든 작업에 적용)

- 캔버스 내부 해상도 **512 x 384**, 타일 **16px**, 플레이 영역 **32 x 24 타일**. `image-rendering: pixelated`, 정수배 확대.
- 고정 timestep **1/60초(약 16.67ms)** 누적 방식. 한 프레임에 물리 스텝 최대 5회로 제한(스파이럴 방지).
- ES module import 금지. 클래식 `<script>`. 로드 순서: `util → assets → input → sfx → level → levels → player → bubble → enemy → item → hud → main`.
- 모든 코드/개체를 `window.BB` 아래에 둔다 (예: `BB.Player`, `BB.CONFIG`).
- 원작(타이토)의 스프라이트·음원·정확한 레벨 레이아웃 재현 금지. 사용자 제작 그림 + `배경음악.mp3` 만 사용. 효과음은 WebAudio 생성 또는 CC0.
- 원본 자료 폴더(`D:\민결이자료\...`)는 **읽기 전용**. `assets/` 로 복사만.
- 사용자 대상 문구는 쉬운 한국어. 개발용 별명·비유 금지.
- 화면 좌우 = 벽, 위아래 = 래핑(아래로 나가면 위에서 등장). 개체 전부 이 규칙 공유.

**인터페이스 (이후 작업이 의존):**
- `BB.CONFIG` — 게임 상수 객체 (`TILE:16`, `VW:512`, `VH:384`, `GRAVITY`, `JUMP_V`, `MAX_FALL`, `STEP:1/60` 등).

- `BB.util.wrapY(obj, vh)` — obj.y 가 화면 위/아래로 벗어나면 반대편으로.
- `BB.assets.images` — `{ '주인공1': HTMLImageElement, ... }` (파일명에서 확장자 뺀 키).
- `BB.assets.load(onProgress)` → Promise, 모든 이미지 + `배경음악.mp3`(Audio) 로드.
- `BB.input` — `BB.input.held('left'|'right'|'jump'|'bubble'|...)`, `BB.input.pressed(name)` (이번 프레임에 눌림), `BB.input.update()` (프레임 끝에 호출).
- `BB.game` — `{ state, score, hiScore, lives, round, setState(s) }`. state: `'BOOT'|'TITLE'|'PLAYING'|'ROUND_CLEAR'|'MISS'|'GAME_OVER'|'ENDING'`.

- [ ] **1.** `index.html`: `<canvas id="game" width="512" height="384">` + `<script>` 태그 12개(순서대로, 현재는 있는 것만) + 인라인 부팅 코드 없음(main.js가 담당).
- [ ] **2.** `css/style.css`: body 검정 배경 가운데 정렬, canvas `image-rendering:pixelated`, JS로 창 크기에 맞춰 정수배 `transform: scale()`.
- [ ] **3.** `js/util.js`: `BB` 네임스페이스 생성 + `BB.CONFIG` + 위 util 함수들. 각 함수에 한 줄 주석.
- [ ] **4.** `js/assets.js`: 이미지 목록 배열 → `new Image()` 로 로드, Promise.all. `배경음악.mp3` 는 `new Audio()`.
- [ ] **5.** `js/input.js`: `keydown`/`keyup` 리스너, 키맵(`ArrowLeft→left` 등, `Space→bubble`, `ArrowUp→jump`, `KeyZ/KeyX→bubble`, `KeyM→mute`, `KeyP→pause`), `held`/`pressed` 구현.
- [ ] **6.** `js/main.js`: 캔버스 컨텍스트, `BB.assets.load` → 완료 시 `BB.game.setState('TITLE')`. 고정 timestep 루프:
  ```js
  let acc = 0, last = performance.now();
  function frame(now){
    acc += Math.min((now-last)/1000, 0.25); last = now;
    let steps = 0;
    while (acc >= BB.CONFIG.STEP && steps < 5){ update(BB.CONFIG.STEP); acc -= BB.CONFIG.STEP; steps++; }
    render(ctx);
    BB.input.update();
    requestAnimationFrame(frame);
  }
  ```
  `update`/`render` 는 `BB.game.state` 로 분기. TITLE: "PUSH SPACE" 텍스트, Space 누르면 `PLAYING`(지금은 빈 화면).

- [ ] **8.** 커밋 `feat: 캔버스 + 게임 루프 + 에셋 로더 + 상태 머신`.

**직접 확인:** `index.html` 더블클릭 → 검정 화면에 "로딩" 잠깐 뜨고 "PUSH SPACE" 표시. Space 누르면 빈 플레이 화면. 콘솔 에러 없음.
